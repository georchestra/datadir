# Datafeeder 2

These files belong to the new Datafeeder: https://github.com/georchestra/datafeeder/

The old Datafeeder is available in geOrchestra's datadir for versions below 26.

Documentation is here: [https://docs.georchestra.org/datafeeder/en/latest/](https://docs.georchestra.org/datafeeder/en/latest/)

Files:
- [datafeeder.env](datafeeder.env): configuration options available for Datafeeder 
- [metadata_template-19115-3.xml](metadata_template-19115-3.xml) : template for metadata in ISO 19115-3 format, used by Datafeeder to generate metadata records
- [metadata_transform-19115-3.xsl](metadata_transform-19115-3.xsl) : XSLT stylesheet used by Datafeeder to apply transformations on XML above
